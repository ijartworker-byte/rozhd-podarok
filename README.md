# Рождественский Подарок

Лендинг сбора на подарки детям (программа «Рождественский Подарок»).

- `index.html` — страница целиком (стили и скрипт внутри)
- `assets/` — фото, логотип, иллюстрация

Собранная сумма задаётся в конце `index.html`: `var COLLECTED = 0;`
Реквизиты — замените блок `[РЕКВИЗИТЫ / QR-КОД / ССЫЛКА НА ОПЛАТУ]`.
